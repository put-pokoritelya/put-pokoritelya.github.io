конфиденциальности

Сайт «Путь покорителя» не принимает платежи, не создаёт личные кабинеты и не собирает данные через формы. Для понимания посещаемости используется веб-аналитика.

Какие данные обрабатываются

При посещении сайта могут автоматически фиксироваться технические сведения: тип устройства и браузера, примерный регион, источник перехода, просмотренные страницы, клики и продолжительность посещения. Эти сведения используются в агрегированном виде и не предназначены для установления личности посетителя.

Не отправляйте персональные данные через параметры адреса страницы, поисковую строку сайта или ссылки с UTM-метками.
